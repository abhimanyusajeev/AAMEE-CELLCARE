AAMEE CELLCARE SOURCE UPDATE - 14 NOVEMBER 2026

Updated areas:
- Products list: client-side search by product name, SKU, barcode, brand, category, and variant.
- Add Product: opening quantity and branch selector; warranty duration supports days, months, and years.
- Edit Product: branch-specific exact stock quantity editing and warranty name/duration editing.
- Product APIs: opening stock creates InventoryItem plus StockMovement and AuditLog records; branch access is checked. Mobile stock remains IMEI/serial tracked and Service items do not use inventory.
- Inventory page: Low Stock and Out of Stock cards toggle their respective lists; each alert row supports updating exact stock quantity inline using the existing inventory adjustment API. Mobile quantity updates remain IMEI/serial managed.

Installation:
1. Back up the current project.
2. Merge this archive's src/ folder into the root src/ folder of the complete Next.js project, replacing matching files.
3. Keep package.json, prisma/, tsconfig.json, .env and all other project configuration from the existing complete project.
4. Run: npx prisma generate
5. Run: npm run dev
6. Verify: npm run build

No Prisma schema migration is included or expected for these changes. Warranty durations are stored using the existing WarrantyPolicy.durationDays field (months are converted as 30 days each; years as 365 days each).
